# Ellie Navigator MVP

1. Initialize Next.js App Router, TypeScript, Tailwind, linting and tests.
2. Build a responsive care-discovery dashboard with synchronized MapLibre heart markers, provider cards, filters, favorites and source details. Only reviewed records enter the public directory; never infer insurance, cost, or availability.
3. Add local-only personal appointment CRUD, calendar, Google Calendar links and escaped ICS export. Clinic booking remains an external action.
4. Add a source-grounded, labeled rule-based Ask Ellie experience; optionally enable a server-only OpenAI route with explicit user opt-in. Add original-source educational resources.
5. Validate lint, types, production build, data/calendar tests and desktop/mobile browser flows. Document Vercel deployment and remaining limitations.

No accounts, real booking, reminders, reviews, or medical diagnoses in the MVP. Store no medical notes. External design/source access may require environment network settings; document verification gaps explicitly.
